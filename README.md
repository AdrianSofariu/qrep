# 🌟 Q-Rep  

**My First Flutter Project – A Smart Quiz & Test Creation App**  

📱 **Q-Rep** is a mobile app designed to help users **create, organize, and prepare for quizzes/tests** on any topic efficiently.  

## 🔍 Features  
✅ **Question Database** – Easily searchable with a **tagging system** for precise categorization.  
✅ **PDF Quiz Generation** – Users can compile and export quizzes in **PDF format**.  
✅ **Collaborative** – Anyone can contribute by adding new questions.  
✅ **Broad Definition of "Question"** – Supports both traditional questions and **math problems**.  

## 🤖 AI Integration (Now Deprecated)  
Previously, Q-Rep featured **GPT-3 integration** as an AI assistant for personalized study help. However, due to **library changes**, this feature is currently unavailable.  

🚀 **Built with Flutter | Firebase for authentication & storage | Dart for PDF generation**
